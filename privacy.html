개인정보처리방침

시행일: 2026년 10월 28일

1. 이용하는 정보

'soom 관리'는 YouTube API 서비스(YouTube Data API, YouTube Analytics API)를 통해 운영자 본인 채널의 영상 정보, 댓글, 분석 데이터에 접근합니다.

2. 이용 목적

운영자 본인 채널의 영상 정보 수정, 댓글 관리, 주간 분석 리포트 작성에만 사용합니다.

3. 보관과 제3자 제공

데이터와 인증 토큰은 운영자의 개인 컴퓨터에만 저장되며, 외부 서버에 올리거나 제3자에게 제공·판매하지 않습니다.

4. 접근 권한 철회

언제든지 Google 계정 권한 페이지에서 이 앱의 접근 권한을 해제할 수 있습니다.

5. 관련 약관

이 앱은 YouTube API 서비스를 사용합니다. 사용자는 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google 개인정보처리방침이 함께 적용됩니다.
